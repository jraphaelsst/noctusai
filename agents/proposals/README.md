# Agent Proposals

Unified folder for proposals generated by ALL agents. When any agent discovers an improvement, the proposal lands here — not inside the agent's own directory.

## Why unified

- **One place to review.** Human checks `agents/proposals/`, sees everything from every agent.
- **No hunting across directories.** Future agents (deployer, monitor, reviewer) all write here.
- **Deduplication works across agents.** If the Keeper and a future reviewer both find the same issue, one proposal — not two.

## Proposal format

Each proposal is a markdown file: `YYYYMMDD-HHMMSS-slug.md`

```markdown
# Proposal: Title

**Generated:** 2026-04-16 15:36
**Severity:** high|medium|low
**Effort:** high|medium|low
**Affected products:** product1, product2
**Status:** pending|accepted|rejected

## Problem
What's wrong and why it matters.

## Proposed Solution
Concrete steps to fix it.

## Acceptance Criteria
- [ ] All tests pass
- [ ] Keeper validates clean
```

## Lifecycle

1. Agent discovers issue → writes proposal here
2. Human reviews → updates **Status** to `accepted` or `rejected`
3. Accepted → implement. Rejected → stays as record with reason.

## For future agent developers

To write proposals from your agent, import the shared proposer:

```python
from agents.keeper.proposer import generate_proposal

generate_proposal(
    title="Your finding",
    problem="What's wrong",
    solution="How to fix",
    affected_products=["product-name"],
    severity="medium",
    effort="low",
)
```

The proposer handles deduplication automatically — same finding won't create duplicate files across runs or across agents.
