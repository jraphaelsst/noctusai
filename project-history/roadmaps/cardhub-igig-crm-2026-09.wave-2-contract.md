# Wave 2 contract — igig CRM (tech-lead, 2026-09-23)

Companion to `cardhub-igig-crm-2026-09.md`. Authored ONCE; every wave-2/3 slice builds to it (contract-first — `.claude/skills/noc-contract-first`). A slice that must deviate says so in its return (`contract-deviation:` line) — never silently.

Conventions (inherited from the foundation `feat/igig-crm-foundation`): success = `{data: …}` envelope; rule refusal = HTTP 409/422 `{"detail": "<pt-BR>", "code": "<code>"}`; org-scoped by the auth context; strict `== 401` unauthenticated. Money = numeric BRL (JSON number). Dates ISO-8601. **Mobile-first (R0)** for every UI: designed at 360–414px first, modals are full-screen sheets <640px, no horizontal page scroll, touch-friendly targets.

Foundation endpoints already live on dev (do not re-implement): stage editors `/api/comercial/pipeline/stages`, `/api/esteira/stages`; `GET /api/comercial/board`; `POST/PATCH /api/comercial/negocios[/{id}]`; `POST /api/comercial/negocios/{id}/mover-etapa {para_etapa_id, novo_indice?, motivo?, orcamento_id?}` (fechado needs orcamento_id → accepts it, ganho, creates Cliente); `POST /api/comercial/negocios/{id}/perder {motivo}`; negocio card hub `/api/comercial/negocios/…`, cliente card hub `/api/clientes/…` (seed card_hub routes); `GET /api/esteira/board?cliente_id=`; `POST /api/esteira/tarefas`; `POST /api/esteira/tarefas/{id}/mover-etapa {para_etapa_id, novo_indice?, motivo?}` (forward 1 step; backward needs motivo); timer iniciar/encerrar (no body); link-aprovacao; public portal. Legacy `GET /api/esteira/quadro` + `POST …/mover` are GONE.

## Shapes

```ts
type Secao = "criacao_conteudo" | "gestao_conta";
interface ProdutoServico { id; secao: Secao; nome; descricao: string|null; preco_base: number; unidade: string; horas_estimadas: number; ativo: boolean; ordem: number }
interface OrcamentoItem { id?; produto_servico_id: string|null; secao: Secao; descricao: string; preco_unitario: number;
  recorrente: boolean; dias_semana: number /* bitmask seg=1 ter=2 qua=4 qui=8 sex=16 sab=32 dom=64 */; qtd_por_dia: number;
  quantidade: number /* used when !recorrente */; quantidade_mensal: number /* SERVER-computed: recorrente ? popcount(dias_semana)*qtd_por_dia*4 : quantidade */;
  subtotal: number /* server: preco_unitario*quantidade_mensal */; ordem: number }
type OrcamentoStatus = "rascunho"|"enviado"|"aceito"|"recusado"|"expirado"|"substituido";
interface LimitesEscopo { revisoes_incluidas: number; valor_excedente: number; observacoes?: string }
interface Totais { subtotal_criacao; subtotal_gestao; desconto; total_mensal; custo_estimado; margem_estimada /* % 0–100, (total-custo)/total */; horas_estimadas }
interface Orcamento extends Totais { id; negocio_id; lead_id; cliente_id: string|null; versao: number; titulo: string; status: OrcamentoStatus;
  validade: string|null /* null = never expires; past validade ⇒ status expirado on read */; itens: OrcamentoItem[]; limites_escopo: LimitesEscopo; observacoes: string|null;
  pdf_key: string|null; enviado_em; respondido_em; aceito_em; recusado_em; motivo_recusa; created_at;
  lead: {id; nome; email; empresa}; negocio: {id; titulo; etapa_id; status} }
interface OrcamentoEmail { id; orcamento_id; direction: "out"|"in"; message_id; thread_id; from_addr; subject; snippet; occurred_at }
```
Custo: `horas_estimadas` of an item = produto.horas_estimadas × quantidade_mensal; custo_estimado = Σ horas × `OrcamentoService.custo_hora_medio(org)` (existing custo/hora spine).

## Slice A — BE orçamentos, produtos, PDF, aceite, contrato (migration 020)
- `GET /api/produtos-servicos?secao=&ativo=` · `POST` · `PATCH /{id}` · `DELETE /{id}` (referenced ⇒ soft `ativo=false`, 200). Seed an org's catalog once with the owner's examples when empty on first GET: Gestão de conteúdo R$500 (gestao_conta), Gestão de DMs R$500 (gestao_conta), Post feed, Carrossel, Reels, Stories (criacao_conteudo, sensible default prices/hours).
- `GET /api/orcamentos?aba=ativos|aceitos|recusados&status=&negocio_id=&lead_id=&cliente_id=&q=` (ativos = rascunho|enviado; recusados = recusado|expirado|substituido) · `GET /{id}` · `POST {negocio_id, titulo?, validade?, itens, desconto?, limites_escopo?, observacoes?}` → 201 (versao = max+1 for the negocio) · `PATCH /{id}` (rascunho|enviado only, else 409 `orcamento_bloqueado`) · `POST /{id}/nova-versao` → 201 clone as rascunho, previous → substituido · `POST /api/orcamentos/calcular {itens, desconto?}` → `{data: Totais & {itens}}` (pure preview, no write).
- `POST /{id}/aceitar` → performs EXACTLY the foundation's fechado transition (reuse that service — negocio moves to the `fechado` stage, ganho, Cliente created) + generates the calendar: for every recorrente criacao item, create `pauta` rows (gerada_automaticamente=true, orcamento_item_id) for the next 30 days per weekday bitmask × qtd_por_dia (pautas ONLY, no esteira tarefas) → `{data:{orcamento, negocio, cliente, pautas_criadas}}`. `POST /{id}/recusar {motivo}`.
- `POST /{id}/pdf` → renders a professional pt-BR PDF (header with agency name/logo if any, lead, validity, two sections table: item · frequência (weekday chips text e.g. "Seg, Qua, Sex × 1") · qtd/mês · unitário · subtotal; totals, limites de escopo, observações) stored in the private `igig` bucket under `{org}/orcamentos/{id}/v{versao}.pdf`, sets `pdf_key` → `{data:{pdf_key, url}}`; `GET /{id}/pdf` → `{data:{url}}` (signed, short TTL).
- `POST /api/orcamentos/{id}/contrato {modalidade_assinatura: "digital"|"fisica", dia_vencimento?}` (aceito only) → creates `contrato` (valor_mensal=total_mensal, posts_por_mes=Σ criacao quantidade_mensal, valor_excedente from limites, orcamento_id) + contract PDF; física = manual signature lines + "feito em N vias" closing, no e-sign; digital = existing dry-run signature path. `POST /api/contratos/{id}/marcar-assinado` (física; multipart optional scanned file → documento_assinado_key) → contrato ativo. `GET /api/contratos?cliente_id=`.
- Remove the legacy `/api/comercial/estimar`, `/api/comercial/orcamentos*` and `/api/comercial/contratos/gerar` endpoints (the FE slice C stops using them) — migrate their tests.

## Slice B — BE e-mail: SMTP, envio, Gmail reply watch (migration 021)
- `GET /api/integracoes/email/smtp` → `{data:{configurado, host, port, username, security, from_email, from_name}}` (NEVER the password) · `PUT {host, port, username, password?, security:"ssl"|"starttls", from_email, from_name}` (password omitted ⇒ keep) · `DELETE` · `POST /testar {para}` → `{data:{message_id}}`. Stored in `integracao` canal `smtp`, secret fields Fernet-encrypted with the cofre, keys per seed `SmtpConfig.from_credentials`. Fallback when the org has none: platform env `SMTP_HOST/PORT/USER/PASSWORD` if set (explicit, logged, surfaced as `origem: "plataforma"` in GET) — never silent.
- `POST /api/orcamentos/{id}/enviar {para?, cc?, assunto?, mensagem?}` → needs `pdf_key` (else 409 `pdf_nao_gerado`) and a recipient (lead e-mail default; else 422 `email_destinatario_ausente`); sends via seed `make_email_sender` with the PDF attached and a pt-BR HTML body; records `orcamento_email` (out, message_id, thread) and sets status `enviado` + `enviado_em` → `{data:{orcamento, message_id}}`. `GET /api/orcamentos/{id}/emails` → `{data: OrcamentoEmail[]}`.
- Gmail: `GET /api/integracoes/email/gmail` → `{data:{conectado, email, watch_ativo, expira_em, configuracao_gcp_ok}}` · `GET /oauth/start` → `{data:{url}}` · `GET /oauth/callback` (redirects to `/integracoes?gmail=ok|erro`) · `DELETE`. Stores refresh token encrypted in `integracao` canal `gmail`; on connect calls `watch` (seed `noctusai_lib.integrations.gmail`) and stores `gmail_watch`. Daily renewal job (lifespan scheduler, pattern of existing product schedulers). `POST /api/webhooks/gmail/push` (public; OIDC-verified via seed `verify_push_token`; audience/SA from env `GMAIL_PUSH_*`) → `list_history` → `get_message_metadata` → seed `match_reply` against sent `orcamento_email` ids → record `orcamento_email` (in), set `respondido_em`, in-app notification (core `public.notifications`, type `orcamento_respondido`, link `/orcamentos?id=<id>`) to the negocio responsável/creator AND an e-mail to the org owner via the org SMTP. Missing GCP env ⇒ `configuracao_gcp_ok=false`, watch not attempted, reported loudly — never a fake success.
