# Seed Product — Live Reference Implementation

## Concept

The seed product (`products/seed/`) is a **real, running product** — the simplest possible implementation that proves the entire shared stack works end-to-end. It's the first stage of any new product's lifecycle, like an embryo that grows into a full product.

The template (`templates/product-seed/`) is **auto-generated from the seed** — a snapshot with placeholders for find-and-replace scaffolding.

## Architecture

```
products/seed/                    ← LIVE running product (source of truth)
    backend/  (port 8004)
    frontend/ (port 8100)
    schema: "seed"

templates/product-seed/           ← AUTO-GENERATED from products/seed/
    Same structure but with {{PLACEHOLDERS}}
    Generated by: scripts/sync-seed-template.sh

backups/seed-versions/            ← VERSIONED BACKUPS (last 5)
    v1/ v2/ v3/ v4/ v5/
backups/template-versions/        ← TEMPLATE BACKUPS (last 5)
    v1/ v2/ v3/ v4/ v5/
```

## Auto-Sync Rules

1. **Source of truth**: `products/seed/` — the running product
2. **Derived artifact**: `templates/product-seed/` — generated, never edited directly
3. **Backup before sync**: always backup both seed + template before overwriting
4. **5-version history**: keep last 5 versions of each (seed + template)
5. **Validation**: after sync, verify all placeholders exist and template structure is valid
6. **Trigger**: manual via script, or automated in CI on seed changes
