# 03 · Reference reports

Thirteen technical reports, one per site, plus three group comparisons. Every site report follows the same 12 sections:

1. Snapshot
2. Positioning & messaging
3. Information architecture
4. Home page anatomy
5. Visual system
6. Motion & interaction
7. Conversion design
8. Trust & proof
9. Pricing
10. Content hub
11. Technical & SEO
12. **Steal / Adapt / Avoid for NoctusAI**

Section 12 in each report is the direct input to the [Pattern synthesis](../04-pattern-synthesis.md).
