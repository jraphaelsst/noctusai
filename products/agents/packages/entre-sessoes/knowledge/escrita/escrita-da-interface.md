# Escrita da interface

## Vocabulário

| Usar | Não usar |
|---|---|
| analisanda (só em documentação; na interface fala-se com "você") | paciente, cliente, usuária |
| análise, sessão | terapia, consulta, atendimento |
| o que veio à mente, lembrança, associação | pensamento automático, distorção cognitiva, crença central, reestruturação, gatilho |
| registro | entrada, log, post |
| Levar à análise | Compartilhar, Reportar |

Tudo no feminino ("você mesma", "curiosa", "segura"). Tratamento por "você". Mônica é citada pelo primeiro nome.

## Estilo

Regras de Mônica para qualquer texto novo:

- Frases diretas, vocabulário comum, sem jargão quando a palavra comum funciona.
- Sem travessão como pausa (usar vírgula, ponto ou parênteses).
- Sem a estrutura "não é X, é Y" e variantes.
- Sem frases motivacionais, sem fechamento de moral da história, sem "lembre-se que".
- Sem emojis.
- Sem séries de três adjetivos ou elementos como ornamento.
- Sem "vale destacar", "é importante notar".
- Sem diagnóstico, promessa de cura ou sentimento tratado como falha.
- Rótulo de botão descreve a ação ("Salvar registro", "Ir para o passo 3", "Copiar texto pra mandar pra Mônica"). Evitar "Continuar", "Saiba mais", "Clique aqui".
- Erros dizem o que fazer para resolver.

Todo texto novo vai para aprovação de Mônica antes de publicar.
