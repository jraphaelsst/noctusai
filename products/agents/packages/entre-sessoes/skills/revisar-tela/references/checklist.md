# Checklist de tela

## Bloqueia
- [ ] Texto de segurança ausente, alterado ou sem links `tel:192` / `tel:188` (RN-28, P4).
- [ ] Algo sai do aparelho sem gesto da analisanda (P1, RN-22, ADR-01, ADR-02).
- [ ] Interpretação, resumo por IA, devolutiva, pontuação, meta, sequência de dias, notificação de engajamento.
- [ ] Texto oficial, pergunta, emoção, despertar, opção do passo 7 alterados ou reordenados.
- [ ] Vocabulário proibido na interface (paciente, terapia em rótulo, cliente, usuária).
- [ ] Texto digitado pela analisanda tratado como HTML ou registrado em log.
- [ ] Perda possível do texto digitado (falha de armazenamento sem mensagem).

## Corrigir
- [ ] Cor fora dos quatro códigos oficiais; rosa velho como texto sobre creme; creme sobre rosa; marrom sobre vinho.
- [ ] Bodoni Moda fora de títulos, citação e números; Inter no resto.
- [ ] Alvo de toque < 48 px; foco sem anel vinho 3 px; não funciona com fonte a 200%; ignora movimento reduzido.
- [ ] Nova superfície escura sem pedido; mais de uma composição principal; texto sobre rosto, flores ou papel.
- [ ] Botão sem verbo de ação; erro sem o que fazer.
- [ ] Aba, ordem de abas ou nome de aba alterados (depende de Mônica).
- [ ] Rótulo de botão ou título de passo diferente do contrato de telas.
