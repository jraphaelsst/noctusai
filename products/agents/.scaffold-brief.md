# Scaffold brief

Captured at scaffold time. The LLM-rewritten prose surfaces (README.md, MASTER-PROMPT.md) reference these answers — edits here should be propagated to those files manually or via a re-rewrite pass.

## What real-world domain does this product serve? (e.g. 'B2B real estate analytics', 'social media post scheduling', 'mental health therapy sessions')

Home of the NoctusAI managed AI agents. Hosts agents that work ON other products through scoped APIs (never direct DB access). First agent: Julia (Claude Agent SDK, headless), web-UI only, who helps run the Academia de Reciclagem project by reading and writing that product's knowledge base with approval. Also lists One Chat — the WhatsApp assistant that keeps running inside social-wiring — with its on/off toggle.

## Who is the primary user? (e.g. 'real estate brokers', 'small business marketing teams', 'licensed therapists')

The NoctusAI owner/team (admins) who chat with Julia, approve or deny her writes, edit her persona, and switch agents on/off.

## What are the 3-5 core entities/concepts? (e.g. for ERP: 'Imovel, Cliente, Negocio, Equipe')

Agent (key, runtime kind, status, owning product for external agents) · AgentPersona (versioned, one active per agent; tone, prompt append, model from allowlist) · Conversation (per agent, per owner) · Message (role, events) · Approval (pending|approved|denied|expired; signed single-use assertion toward the target product)

## Describe 1-3 primary workflows the product enables, end-to-end.

1) Chat with Julia: send a message -> agent turn streamed over SSE with tool cards -> any write to Academia asks first -> approve/deny inline -> approved write lands in Academia's knowledge DB with provenance; timeout denies. 2) Manage agents: list agents, switch Julia on/off, switch One Chat's auto-reply on/off through social-wiring's scoped API, edit Julia's persona (admin-only). 3) Audit: see approvals and switches history.

## External services this product integrates with (LLMs, APIs, webhooks, etc.). 'none' is fine.

Claude Agent SDK (claude-opus-5) + Anthropic API; academia-de-reciclagem scoped API (product token, scopes academia:*); social-wiring scoped toggle API for One Chat; noctusai_lib.realtime SSE; core SSO + credential vault. No WhatsApp/WAHA in this product for now.

## How will we know the product is doing its job? (key metrics, user outcomes)

Julia usable from the browser with streamed replies; every Julia write to Academia visible there with its approval id; Julia and One Chat on/off switches work and are audited; isolation tests prove Julia cannot reach social-wiring or other products' data and has no platform secrets in her environment.

## Naming conventions specific to this product's domain? (e.g. 'use Portuguese for entities, English for code')

UI copy PT-BR; code, commits and technical docs EN. Agent keys are stable kebab-case ids (julia, one-chat).
