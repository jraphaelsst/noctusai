# PostFrame

The canvas zones of each format the brand publishes. Required in every branding.

## Fill in, per format (9:16 Stories/Reels cover · 4:5 feed and carousel)
- **Type zone** — which share of the height holds the HeadlineStack.
- **Scene zone** — what the image or illustration shows and where it sits.
- **Safe zone** — `safe-bottom` on 9:16; nothing key there.
- **Variants** — light and dark grounds, and when each is used.
- **Carousel rule** — what repeats on every slide and what changes.
