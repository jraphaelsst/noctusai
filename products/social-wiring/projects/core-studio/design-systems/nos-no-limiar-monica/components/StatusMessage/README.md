# StatusMessage

Inline confirmation and error messages.

- `offWhite` ground, `radius-tile`, padding 12 × 14, a 3px left rule in the status colour: `moss` success, `brick` error, `ochre` warning.
- The first phrase is bold in the status colour and says what happened; the rest is `ink` and says what to do. Inter 400 14/20.
- Examples: "**Guardado.** A atividade está em Salvos." · "**Não foi possível salvar agora.** Tente de novo em instantes."
