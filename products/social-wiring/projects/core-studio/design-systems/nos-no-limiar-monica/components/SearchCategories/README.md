# SearchCategories

The home screen's search pill and the row of four category tiles (Criar, Sair, Aprender, Conectar).

## Search
- Height `field-h` (52), `radius-pill`, `offWhite` ground, Inter 400 16, placeholder in `ash`: "Buscar atividades…", search icon leading.

## Category tiles
- Tile 52 × 52, `radius-tile` (12), ground `linen` (neutral), `rose` (highlighted) or `tan` (warm); icon 22 in `ink`, or `wine` on the highlighted tile.
- Label under the tile: Inter 500 12, `ink`, 72 wide, centred.
- The consumer provides the icons (Phosphor, light).
