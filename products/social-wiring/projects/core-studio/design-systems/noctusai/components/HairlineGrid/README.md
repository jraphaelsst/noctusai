# HairlineGrid

The modular cell grid every home section sits on.

- Grid of cells with a 1px `hairline` gap over a `hairline` ground and border, so the lines read as one continuous grid.
- Cells: `bg`, padding 32 × 24, title in 18px 600, text in `fg-muted`.
- Columns: auto-fit, min 220px. A hidden section never leaves a hole.
