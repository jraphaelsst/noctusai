# Button

Flat 8px buttons: one cyan primary per view, a bordered default and a ghost.

- Base: padding 10 × 20, `radius-md`, 1px `border`, `ui` style (15px, 600), transparent ground, `fg` text. Hover: `border-strong`.
- **Primary**: `action` ground, `action-fg` label, no border; hover `action-hover`. Primary CTA only.
- **Ghost**: no border (header "Entrar").
- CTAs come in a pair (primary + secondary), 12px apart. Focus: 2px `focus-ring`, offset 2.
