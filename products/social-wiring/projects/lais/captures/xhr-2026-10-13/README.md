# Stage 2 read-only capture — 2026-10-13

**Method.** A script ran inside the owner's logged-in `casa.lais.ai` tab and called the BFF the way
the app does (`Authorization: Bearer <session token>` + `x-agency-id: <own agency>`). It used GET only,
the S1 allowlist only, and only the agency's own ids (the two already-read chats). Each request had a
10 s timeout (one GET hung forever without it). Responses were scrubbed of token-like keys and kept
**in the browser tab only**. What was read out of the tab is shown below: response **shapes**
(keys + types), plus non-personal config values (in `../../analysis/agent-brain.md`). **No raw
response was downloaded and no lead data is stored.** The tab was reloaded afterwards.
~100 calls, 252 KB in the tab.
