# Chip

Small uppercase labels for category and state, plus the round icon buttons that sit beside them.

## Chips
- `chip` type style (Inter 600 12/16, +0.8px, uppercase), padding 4 × 10, `radius-pill`.
- **Wine** (`wine` / `offWhite`): the selected or primary category. **Charcoal** (`charcoal` / `offWhite`, 7.62:1). **Sand** (`sand` / `ink`; never stone or ash on sand).

## Icon buttons
- 48 × 48 (`space-48`, the minimum touch target), round.
- **Wine**: `wine` ground, `offWhite` icon, the act-now arrow. **Paper**: `offWhite` ground, `ink` icon (save/bookmark). **Plain**: no ground, `ink` icon (notifications).
- Every icon button carries an `aria-label`.
