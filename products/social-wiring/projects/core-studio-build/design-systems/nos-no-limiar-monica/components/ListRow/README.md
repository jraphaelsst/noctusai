# ListRow

A tappable row, the activity checklist and the meta line that states an activity's cost.

## Anatomy
- **Row** — `offWhite` ground, `radius-card`, padding 14 × 16, min height 72, max 380; a 44 round `rose` icon disc (icon in `wine`), title in `cardTitle`, subtitle in `caption` (`ash`), trailing chevron in `ash`.
- **Checklist** — 26 round `rose` disc with a `wine` check; text in Lora 15/22 `stone`.
- **Meta** — Inter 400 14 `stone`, icon + text pairs 18 apart: duration, energy, place ("10–15 min", "Energia baixa", "Em casa").
