# Eyebrow

The section opener: a mono eyebrow, then a heading with ONE accent-gradient word.

- Eyebrow: `eyebrow` style (NX Mono 13px, uppercase, +0.06em), `accent`, a leading ● at 8px, 16px above the heading.
- Heading: `h2`, `fg`. One word gets `accent-gradient` (accent-7 → cyan-6) clipped to text.
- Subcopy: `body` in `fg-muted`.
