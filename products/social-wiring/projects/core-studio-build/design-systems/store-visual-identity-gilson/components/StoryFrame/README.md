# StoryFrame

The 1080 × 1920 (9:16) post template: type block on top, collage scene below, navy slab anchoring the composition.

## Zones
- **0-40% height** — HeadlineStack at `margin-x` / `text-top`.
- **40-87%** — scene: foil disc center-right, one grayscale hero cut-out overlapping it, hairline accents.
- **Bottom ~13% (250px)** — navy floor / slab only; no key content (Instagram UI).
- **Right edge** — optional vertical torn navy strip, 120-180px wide, full height or top half.

## Variants
- **Paper** (default): `surface` = paper, slab = navy.
- **Midnight**: `surface` = midnight, slab = cream paper. For the darkest topics.
- **Carousel reveal**: same HeadlineStack; the scene changes and reveal words are engraved into objects (`engraved-label`).

The consumer provides the hero photo and the copy.
