# HeadlineStack

The type block every post opens with: serif headline with one gold keyword, a sans deck that finishes the sentence, and a short gold rule.

## Anatomy
1. **Headline** — `display-caps` (2-4 lines, caps) or `display-mixed` (sentence case, tight). Color `headline`.
2. **Keyword** — exactly one word or line in `keyword` (gold). The word that carries the threat or the action.
3. **Deck** — `deck` or `deck-caps` (match the headline's case), color `deck`, ends with a period. Optional gold phrase in `deck-strong` + `keyword-small`.
4. **Rule** — `rule-w` × `rule-h`, color `accent-line`, `gap-deck-rule` below the deck.

## Rules
- Flush-left on `margin-x`, top at `text-top`. Never centered.
- Occupies the top ~40% of the canvas; art never crosses it (a torn side strip may run beside it).
- Carousels repeat the identical stack on every slide.
