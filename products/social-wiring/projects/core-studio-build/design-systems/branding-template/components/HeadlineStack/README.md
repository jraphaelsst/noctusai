# HeadlineStack

The type block every post opens with: headline, emphasis, deck, closing mark. Required in every branding.

## Fill in
1. **Headline** — which style (`headline` / `headline-alt`), casing, line count, colour `headline`.
2. **Emphasis** — how a keyword is marked (colour `keyword`, weight, how many per headline).
3. **Deck** — style `deck`, colour `deck`, punctuation rule.
4. **Closing mark** — rule, signature line or none.
5. **Placement** — alignment and position on the canvas (`margin-x`, `text-top`), how much height it may take.
